# Спека: фильтр выполненных задач

## Цель

Добавить фильтр выполненных задач для команды `list`.

## Текущее поведение

```bash
python3 todo_cli.py list
```

Показывает все задачи:

```text
[x] написать спеку
[ ] ревью диффа
```

## Целевое поведение

```bash
python3 todo_cli.py list --done
```

Показывает только выполненные задачи:

```text
[x] написать спеку
```

## Не-цели

- Не добавлять зависимости.
- Не менять формат `TASKS`.
- Не переписывать утилиту целиком.
- Не добавлять сохранение задач в файл или базу данных.

## Критерии готовности

1. `python3 todo_cli.py list` по-прежнему показывает все задачи.
2. `python3 todo_cli.py list --done` показывает только выполненные задачи.
3. Вывод `list --done` не содержит строку `ревью диффа`.
4. Дифф маленький и касается только нужного сценария.
5. В хэндофе указано, как именно вы проверяли результат.

## Проверка

Основная проверка:

```bash
python3 todo_cli.py list
python3 todo_cli.py list --done
```

Если у вас установлен `pytest`, добавьте тест на новый сценарий и запустите:

```bash
python3 -m pytest
```

Если `pytest` не установлен, используйте ручную проверку и честно запишите это в `docs/handoff.md`.

## На что смотреть в ревью

- Флаг `--done` должен быть частью команды `list`, а не отдельной командой.
- Старый сценарий `list` не должен сломаться.
- В коде не должно появиться лишней архитектуры ради одной маленькой фичи.
