# Кэпстоун todo

Это маленький starter для кэпстоун-проекта курса «Вайб-кодинг».

В нём уже есть простая консольная утилита на Python, один baseline-тест и спека задачи. Ваша задача — не создать проект с нуля, а пройти полный агентный цикл на маленьком изменении: понять спеку, дать агенту контекст, получить дифф, проверить результат и написать хэндоф.

## Что внутри

```text
capstone-todo/
  README.md
  todo_cli.py
  pyproject.toml
  docs/
    spec.md
    handoff.md
  tests/
    test_todo_cli.py
```

## Быстрый старт

```bash
python3 todo_cli.py list
python3 todo_cli.py --help
```

Ожидаемый вывод первой команды:

```text
[x] написать спеку
[ ] ревью диффа
```

Если у вас установлен `pytest`, можно запустить baseline-тест:

```bash
python3 -m pytest
```

Если `pytest` не установлен, это не блокер для бронзового прохождения. Используйте ручную смоук-проверку:

```bash
python3 todo_cli.py list
python3 todo_cli.py --help
```

## Задача

Добавьте флаг `--done` для команды `list`.

После изменения команда:

```bash
python3 todo_cli.py list --done
```

должна показывать только выполненные задачи:

```text
[x] написать спеку
```

Подробная спека лежит в [`docs/spec.md`](docs/spec.md).

## Что сдавать

1. Ссылку на репо или архив.
2. Сводку диффа.
3. Команды проверки и фактический вывод.
4. Заполненный хэндоф из [`docs/handoff.md`](docs/handoff.md).

Хороший результат здесь маленький: один понятный сценарий, короткий дифф, проверка и честные заметки о рисках.
